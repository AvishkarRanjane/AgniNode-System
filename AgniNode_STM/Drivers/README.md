# Driver source provenance

The HAL and CMSIS device files are vendored from STMicroelectronics' official
STM32CubeG0 repository and its pinned submodules:

- STM32CubeG0: `51075a5d4cb5147e46e3747ecaa3b699377c330f`
- STM32G0 HAL driver: `289ef6c8ff0922878e99d253f29be76851f8f28e`
- STM32G0 CMSIS device: `7c77b7cbcee497dfbb5cc08f9562a80515e78013`

The CMSIS core license is in `CMSIS/LICENSE.txt`; the device and HAL
submodule licenses are in their respective driver directories.
